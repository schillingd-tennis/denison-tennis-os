# Denison UTR Capture

Browser helpers for Today Beta UTR results import (Isaac Lewis proof-of-concept).

## Chrome (recommended for local testing)

Load unpacked in Chrome — no build step, no Xcode:

```
browser-extensions/denison-utr-capture/chrome/
```

See **[chrome/README.md](./chrome/README.md)** for step-by-step install instructions.

## Safari (optional)

Safari Web Extension + macOS wrapper for future use:

See **[macos/README.md](./macos/README.md)** and run `./macos/sync-utr-extension-resources.sh` before building in Xcode.
